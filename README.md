# 游戏内渲染队列与批处理系统

## 项目描述

游戏内渲染队列与批处理系统的bug修复项目。核心模块 `rendering/render_queue.py` 存在多个已知bug，需要修复后使测试全部通过。

## 已知问题

- 渲染队列完全没做渲染顺序是随机的
- 批处理完全没做不能合批
- Draw Call优化完全没做不能减少Draw Call
- 状态排序完全没做不能按状态排序
- 渲染通道完全没做不能分通道渲染
